# 宝塔自动部署

这个项目已经接好了构建后自动上传脚本。

## 用法

1. 把根目录的 `.env.deploy.example` 复制为 `.env.deploy.local`
2. 填好宝塔服务器的 SSH 信息和站点目录
3. 如果要每次 `npm run build` 后自动上传，把 `DEPLOY_AFTER_BUILD` 改成 `true`

## 命令

- `npm run build`
  - 正常构建
  - 当 `.env.deploy.local` 存在且 `DEPLOY_AFTER_BUILD=true` 时，构建完成后自动上传
- `npm run deploy:bt`
  - 直接把当前 `dist` 上传到宝塔，不重新构建

## 说明

- 默认通过 `ssh + scp + tar` 部署，不依赖宝塔面板插件
- 默认只允许部署到 `/www/wwwroot/` 下，避免误删其他目录
- 部署时会清空目标目录里的旧前端文件，但默认保留 `.user.ini` 和 `.well-known`
- 更推荐配置 SSH 私钥；如果不配私钥，会走系统默认 SSH 认证方式
